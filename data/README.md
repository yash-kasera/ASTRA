# Data

| File | What it is |
|---|---|
| `incidents.csv` | 18 digital exam failures in India (2009–2026) with news sources |
| `centres.json` | Simulated exam centres and rooms (not real) |
| `sample_paper.json` | Sample questions in English and Hindi, written by the team |
| `invigilator_messages.csv` | Example invigilator reports (English, Hindi, Hinglish) with the expected problem type, for testing the AI |
